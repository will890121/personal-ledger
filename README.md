# Personal Ledger

Personal Ledger 是以 Telegram 為主要介面的個人記帳服務。M2 支援收入、現金與信用卡支出、帳戶間轉帳、卡費、手續費、退款、軟刪除、稽核軌跡，以及今日／本月雙口徑摘要。

## 環境需求

- Node.js 24 LTS
- pnpm 10.x；本機工具亦相容 pnpm 11
- Docker 28 或更新版本

## 設定

```bash
pnpm install --frozen-lockfile
cp .env.example .env
```

在本機填寫 `.env`。不得提交真實 Telegram token 或使用者 ID。

## 開發與檢查

```bash
pnpm dev
pnpm check
```

Bot 使用 long polling，只有 `LEDGER_OWNER_ID` 指定的 Telegram 私人對話可使用；群組與其他使用者的更新會被忽略。以 `SIGINT` 或 `SIGTERM` 結束，讓 Bot 與 SQLite 正常關閉。

## 支援輸入

確定性 parser 支援下列形式：

```text
午餐 120
薪水 +85000
昨天 Uber 245 國泰卡
台新轉國泰 5000
國泰卡刷 1200
繳國泰卡 18000 從台新
台新轉國泰 1000 手續費 15
```

帳戶與商家名稱必須已存在。未知或同名參照不會猜測，也不會建立草稿。每筆草稿仍須按「確認」才會正式入帳。

一則訊息可以同時記錄多筆。以逗號、頓號或換行分隔，一次最多 10 筆；超過會要求分次輸入：

```text
午餐 120，Uber 245
午餐 120
Uber 245
```

不含金額的片段會併回前一段，因此 `聚餐 1260，我先付` 仍是一筆交易。

解析不完整的項目不會被丟棄，而是留下待補草稿並立即追問：分類與帳戶以候選按鈕選擇，金額請回覆該則追問訊息並輸入數字。完全無法解析的輸入只會得到範例提示，不會留下待辦。

可用指令：

- `/recent`：最近 50 筆未刪除交易。
- `/today`：今日實際資金流與個人財務摘要。
- `/month`：本月第一日至今日的摘要與分類排名。
- `/pending`：待補充與待確認的草稿，可重新預覽、封存或關閉清單。重新呼叫會關閉前一份清單，避免同時存在內容不同步的多份清單。
- `/advances`：依交易對象列出未回收代墊，可記錄收款、放棄回收與翻頁。

草稿不會自動刪除。建立日期不是今天的草稿，按下舊訊息裡的「確認」不會直接入帳，而是重新顯示完整預覽並要求再確認一次，避免誤觸幾天前的按鈕。

交易可透過明確 callback 軟刪除；M3a 不支援自由文字修改追問。所有正式異動均需來源事件並留下不可變 audit。退款必須關聯同一擁有者的未刪除支出交易。

## 代墊與回收

記一筆帳時可以同時分帳，代墊的部分會歸到指定的交易對象名下並計入應收，個人負擔的部分才計入自己的支出：

```text
聚餐 1260，我先付，朋友欠一半
午餐 999，小明欠一半
午餐 1260，小明欠 630
```

支援兩種分帳寫法：

- **平分**：`一半`、`各半`、`平分`、`N 個人平分`（人數請用中文數字，如「三個人平分」；人數含本人，`一半` 等同兩人）。每人負擔 = 總額 ÷ 人數；除不盡時不會四捨五入決定，而是追問每人負擔金額，追問訊息會明確寫出總額與人數。阿拉伯數字人數（如「3個人平分」）目前會被誤認成第二個金額而要求補金額，請一律用中文數字。
- **明確金額**：`X 欠 <金額>`（也接受「要還」「該給」），用來表達不等額分帳。一則訊息以逗號、頓號或換行分隔多筆交易時，純粹的欠款子句（例如「小明欠 630」）會被視為前一段的分帳明細併回同一筆交易，不會被切成獨立的第二筆交易。

分帳語句裡的名字必須是已存在的交易對象；不存在時會追問「要建立這個交易對象嗎？」並附「建立並繼續」「取消」兩顆按鈕，按下即建立並補完草稿。多人分帳時只要有人缺交易對象或除不盡，都會逐人追問直到補齊。

`/advances` 依交易對象列出未回收代墊，逐筆顯示原金額、已回收與餘額，每頁 10 筆可翻頁並可關閉清單；每位對象提供「記錄收款」，每筆代墊提供「放棄回收」。

回收（還款）可以直接打字，也可以用 `/advances` 的「記錄收款」按鈕後回覆金額：

```text
小明還 300
收到小明 300
```

系統以先進先出沖抵該對象最早的代墊，一次還款可能沖抵多筆；金額超過未回收總額時，超出部分會另外追問分類，不會自動當成該對象的還款。

放棄回收會把尚未收回的餘額轉為個人消費，計入原交易發生日期所屬的月份，而不是放棄當下的日期；已回收的部分維持不變。`/advances` 的「放棄回收」按鈕會先顯示金額並要求再次確認才生效。代墊交易一旦有回收關聯指向它，就無法被軟刪除，須先處理該筆回收。

## Docker 與升級

升級前請自行備份 SQLite 檔案或 `ledger-data` volume，再執行：

```bash
docker compose build
docker compose up -d
```

啟動時會自動依序執行 migration 與參照資料 bootstrap。任何 migration 或完整性檢查失敗都會停止啟動，不會開始 Telegram polling。`ledger-data` volume 保存 `/app/data/personal-ledger.sqlite`；憑證只由本機 `.env` 注入，不會複製進 image。
